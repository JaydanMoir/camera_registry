# Единый реестр камер — демо-версия

> **Демо-версия.** Кликабельный прототип и проект ТЗ для обсуждения. Все камеры, организации, заявления, контакты и события — вымышленные демо-данные. Это не рабочая система и не официальный документ.

Платформа согласования добавления и заведения камер видеонаблюдения и единый реестр камер Единой системы видеонаблюдения (ЕСВ) Ямало-Ненецкого автономного округа.

## Что внутри

| Путь | Что это |
|---|---|
| `prototype/index.html` | Кликабельный прототип: рабочие места владельца камер, ДРБ и оператора ЕСВ. Открывается в браузере, работает без сервера |
| `docs/lifecycle.html` | Модель жизненного цикла камеры: камера и заявление, две оси состояния |
| `tz/ТЗ Единый реестр камер v1.5 (проект).docx` | Проект технического задания на прототип |
| `tz/build_tz.py` | Скрипт сборки ТЗ (python-docx) |

## Как посмотреть прототип

Скачайте `prototype/index.html` и откройте в браузере — или включите GitHub Pages для репозитория (Settings → Pages → ветка `main`, папка `/root`) и откройте `…/prototype/`.

Слева переключаются рабочие места. Данные хранятся только в вашем браузере; кнопка «Сбросить демо-данные» возвращает исходное состояние.

В прототипе есть раздел **«Инструкция»**: зачем нужна платформа, путь камеры из шести этапов, пошаговые действия владельца, ДРБ и «Ресурсов Ямала», частые вопросы.

## Ключевые идеи

- **Вся логика на сервере.** В прототипе её имитирует модуль API в браузере: проверки, переходы состояний и права выполняются в нём, интерфейс только отображает. Запреты видны в журнале вызовов API.
- **Камера ≠ заявление.** Камера — постоянная запись реестра; заявления (размещение, изменение, вывод) её меняют.
- **Две оси состояния:** размещение и подключение к ЕСВ; «путь камеры» из шести этапов с ответственным и сроком.
- **Данные в два этапа:** минимум при заявлении, полные данные для ЕСВ — после одобрения.
- **Пароли камер** хранятся в зашифрованном виде и в интерфейсе не показываются.
- **Добавление в ЕСВ** — один экран проверки у оператора и кнопка «Добавить в ЕСВ» через API.

## Картографическая подложка

Подложка берётся напрямую из TileServer Единой картографической системы ЯНАО (`map.yanao.ru`, сервис `common/basemap`, EPSG:3857) — так же, как `TileLayer` в Leaflet/folium:

```
https://map.yanao.ru/elitegis/rest/services/common/basemap/MapServer/tile/{z}/{y}/{x}
```

Доступен весь округ и уровни приближения до 19. Адрес точки камеры определяется по адресному плану ЕКС (`common/addr`, слой «Здания и сооружения»): адрес здания, в контуре которого стоит точка, или ближайшего в пределах 150 м, с кодом ФИАС. Онлайн — по всему ЯНАО, во встроенной копии — по г. Ноябрьску. Если сервис недоступен (например, с зарубежного IP), прототип сам переключается на встроенную копию: весь ЯНАО на обзорных масштабах и г. Ноябрьск детально. Режим подписан в углу карты: «онлайн» или «встроенная копия». Права на картографические данные принадлежат их правообладателю; подложка используется только для демонстрации.

## Развёртывание

В репозитории есть `Dockerfile` (Node.js) и `docker-compose.yml` (приложение + PostgreSQL) для развёртывания на своём сервере, например через Dokploy. На сервере данные демо общие для всех участников. Инструкция — в [DEPLOY.md](DEPLOY.md).
